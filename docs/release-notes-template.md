# v1.0.4

**时间管理器 · Time-Manager（Android）v1.0.4**

## 本次修复

- **竖屏周视图也显示日历了**：与月视图一致「日历在上、时间表在下」，不再只剩一块时间表。
- **修复周视图表头出现两个「周六」**：表头按 ISO 星期 1..7 取星期名，第 7 天被 `coerceIn(0, 6)` 钳成 6（周六）。改为对 7 取模，周日恢复为「日 / Sun / 日」。
- **修复横屏日期数字显示不全**：日期格被压到 26dp 左右时，字号（13sp→10.5sp）、上边距（6dp→1dp）、圆点半径与底部间距全部自适应收缩，360dp 高的短横屏也能完整显示。

## 质量

- 单元测试 **44 个全部通过**（数据格式、提醒归一化、周视图布局、启动稳定性、三语文案、320dp / 411dp / 竖屏 / 横屏 / 矮横屏五种屏幕的布局实测）。
- 新增矮横屏布局回归 `SmallLandscapeLayoutTest`（740×360dp）与星期表头回归用例（`isoIndexSevenIsSunday`、`weekHeaderHasSevenDistinctLabels`）。

## 安装

1. 下载下方附件 `Time-Manager-Android-1.0.4-debug.apk`；
2. 手机上直接点开安装（同签名覆盖安装，**原有日程与设置全部保留**，不需要卸载旧版）；
3. 需要提醒的话，在系统设置里给「时间管理器」打开 **通知** 与 **闹钟和提醒** 权限。

## 更新内容说明

- 本版本仍为 debug 签名的安装包，属于个人使用版本，不上架应用商店。
- 如果是从 1.0.0 / 1.0.1 升级，历史修复（闪退、周视图只有 0–7 点、添加日程日期显示成 `2026/…` 等）也一并包含在内，详见 README 的「更新记录」。
