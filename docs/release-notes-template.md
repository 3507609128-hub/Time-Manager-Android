# v1.0.5

**时间管理器 · Time-Manager（Android）v1.0.5**

## 本次修复

- **修复「设置 → 提示音 → 试听」没声音**：原来试听走的是通知音量，手机上把通知音量调成 0、或开了免打扰，按试听就完全没有声音。现在试听单独走**媒体音量**，提醒到点仍按通知音量播放。
- **播放链路整体重写**：`MediaPlayer` → `Ringtone` → `ToneGenerator` 蜂鸣三层回落，部分 ROM 取不到系统提示音 URI 时也不会静默失败。
- **修复提醒双响**：通知通道自带默认提示音，会和用户选的音效叠在一起（选「静音」时也还会响）。提醒通道改为 `reminder_v2` 且通道静音，提示音完全由设置决定。
- **「哔声」选项**以前只震动不发声，现在是真的蜂鸣音。
- **自定义音频失效**（文件被删 / 授权丢失）时改为播放兜底蜂鸣并保留提醒，不再静默。
- 试听时弹一条提示（`试听：信息提示（叮咚）`，若无声请检查媒体音量），方便区分「按钮没点到」和「音量问题」。

## 质量

- 单元测试 **47 个全部通过**（数据格式、提醒归一化、周视图布局、启动稳定性、三语文案、五种屏幕布局、设置试听接线）。
- 新增 `SoundPreviewTest`（2 条）守住试听接线：点「试听」必须把当前音效交给播放层，选「静音」只提示不播放。

## 安装

1. 下载下方附件 `Time-Manager-Android-1.0.5-debug.apk`；
2. 手机上直接点开安装（同签名覆盖安装，**原有日程与设置全部保留**，不需要卸载旧版）；
3. 需要提醒的话，在系统设置里给「时间管理器」打开 **通知** 与 **闹钟和提醒** 权限。

## 说明

- 本版本仍为 debug 签名的安装包，属于个人使用版本，不上架应用商店。
- 1.0.5 的安装包已覆盖为包含上述修复的版本（`versionCode 7`，可直接覆盖旧的 1.0.4 / 1.0.5 安装）。
- 从 1.0.0 升级的话，历史修复（闪退、周视图只有 0–7 点、添加日程日期显示成 `2026/…`、横屏日期被裁等）也一并包含在内，详见 README 的「更新记录」。
